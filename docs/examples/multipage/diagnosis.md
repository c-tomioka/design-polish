# アンケン帳 診断と変更の記録

ユーザー不在のため確認を省いて進めた。選んだ方向性は次のとおり。

> **帳面の罫線と藍インク。** アンケン帳は、個人や小さな事務所が案件・納期・請求額を毎日つける帳簿。主役は納期と金額なので、面は影やグラデーションでなく罫線で区切り、数字は等幅で桁を揃える。色は紙に寄せた無彩色と藍インク1色に絞り、藍は「押せるもの」と「いまいる場所」だけに使う。

成果物

- `polish.css`:共通層のCSS(確認用の上書きCSS)。右下のボタンか Alt + P で前後を切り替えられる
- この文書:診断、対応表、ページ固有の変更一覧(未適用)、報告

## 対象

代表ページ:案件一覧(`index.html`)、案件の詳細(`detail.html`)、設定(`settings.html`)の3枚。サイトの全ページにあたる。
部品の状態は `states.html`(状態一覧)で確かめた。
未確認の型:なし(文章中心のページ、トップページはこのサイトにない)。

把握したこと

- 製品:デザイン事務所などの個人事業主が、案件・納期・金額・請求を管理する帳簿。毎日開く作業画面
- 各ページの役割:一覧=案件を見渡して探す/詳細=1件の進み具合を確かめ、請求書やメモを作る/設定=請求書に載る情報を整える

## 診断

共通層の判定:**改修**
ページ固有層の判定:一覧=**調整**、詳細=**改修**、設定=**改修**

### 共通層

高

- アクセント色が決まっていない。藍・紫・桃のグラデーションが11か所にあり、主ボタンは3ページで3通り(`base.css` 25行目、`index.html` 21行目、`detail.html` 15行目、`settings.html` 16行目)
- 読めない文字がある。補助文、表の見出し、注記、バッジ4種、お知らせ、要約の白文字が基準未満(上の表)。請求予定額 `¥1,284,000` は比1.28
- 値に体系がない。文字サイズ15種類、余白29種類、角丸9種類、影13種類、色55通り
- 要約の数値4枚がそれぞれ別の色のグラデーション面で、主役であるはずの表より強い(`index.html` 11〜15行目)
- フォーカスが見えない。入力欄は `outline: none`(`base.css` 54行目)、ボタン・タブ・ナビは指定なし

中

- ページ見出しがページごとに違う。詳細はグラデーション文字、設定だけ中央寄せで、左揃えのフォームと基準線が合わない(`detail.html` 10行目、`settings.html` 11〜13行目)
- すべての面に影があり、6種類は色つきの発光。浮いている物(モーダル、お知らせ)と区別がつかない
- 角丸が大きく(18〜24px、999pxが10か所)、作業画面としては締まりがない
- 危険ボタンが主ボタンと同じ強さで並ぶ(`base.css` 26行目)
- 和文の指定がない。書体は読み込まれていない `Inter` が先頭で和文書体の指定なし、行間1.5、太さは700と800が中心
- 表の見出しとラベルに `text-transform: uppercase` と字間1px。和文には効かず、詳細の英語ラベルだけが浮く
- 金額が等幅数字でなく、右揃えでも桁が揃わない

低

- `transition: all 0.3s`、ホバーで浮くボタン、弾むお知らせ。動きを減らす設定への対応なし
- モーダル背後のぼかし(`backdrop-filter: blur(6px)`)
- 無効ボタンが `opacity: 0.5` だけで、押せない理由が形に出ていない

## 方向性

- **人格**:帳簿をきちんとつける、個人事業主の事務の相棒。静かで正確。励まさないし、驚かせない
- **主役**:納期と金額。一覧では表、詳細では案件名とその下の数字の帯。ほかはそれを立てるために引く
- **色**:紙に寄せたわずかに温かい無彩色(背景 `#f5f4f0`、面 `#fdfcfa`、本文 `#1f1e1b`)と、藍インク `#343c9c` の1色。元の藍(`#6366f1`)の色相を残して、読める濃さまで沈めた。藍を使うのは主ボタン、リンク、いまいる場所の下線(ナビ、タブ)、フォーカス、チェック、進捗。面の塗りや見出しには使わない。赤は危険とエラー、緑と黄土は状態の印だけ
- **文字**:端末の和文ゴシック(追加の読み込みなし)。太さは400と600の2種類。大きさは 12 / 14 / 16 / 20 / 24 の5段階。本文14px・行間1.7、見出しは行間1.4
- **決め手**:帳面の罫線。面は影でなく1pxの罫線で区切る。表は見出しの下だけ濃い罫、行は薄い横罫。要約の数値は1枚の面を罫線で4つに割る。日付と金額は等幅数字で桁を揃える

置き換えの罠との照合:紙色の背景は使うが、明朝体も黒い丸ボタンも使っていない。白黒と罫線だけにはせず、藍に「押せる・いまここ」という役割を持たせた。罫線と等幅数字は帳簿だから選んだもので、告知ページや会話アプリにそのまま持っていける見た目ではない。

## 対応表

文字サイズ(15種類 → 5段階)

```
11px, 12px                    → 12px  注記、表の見出し、日付、エラー文
13px, 14px, 15px              → 14px  本文、ボタン、入力欄、ラベル、タブ、ナビ、補助文
16px, 17px, 18px(要約以外)  → 16px  小見出し、ロゴ
19px, 20px, 21px, 22px        → 20px  モーダルの見出し、スマホ幅のページ見出し
18px, 28px(要約の数値)      → 20px  一覧と詳細で同じ大きさに
25px, 30px                    → 24px  ページ見出し
```

太さ(3種類 → 2種類)

```
600, 700, 800 → 600  見出し、ボタン、ラベル、表の案件名、いまいる場所
(指定なし)    → 400  本文、補助文、バッジ、選ばれていないタブとナビ
```

余白(29種類 → 8段階)

```
2, 4, 6                → 4    ラベルと入力欄の間、注記の上
7, 8, 9, 10            → 8    ボタンの上下、ボタン同士の間
11, 12, 13, 14, 15     → 12   表のセル、入力欄の左右、行の上下
16, 17, 18, 19         → 16   項目の間、ボタンの左右、スマホ幅の面の内側
20, 21, 22, 23, 24, 25, 26 → 24   面の内側、面と面の間、ページの左右
27, 28, 29, 36         → 32   ページの上、空状態の上下
60, 70                 → 64(スマホ幅は48)  ページの下
```

角丸(9種類 → 2種類)

```
6, 8, 10, 999px(ボタン、入力欄、お知らせ)  → 4px
12, 16, 18, 20, 24px(カード、要約、モーダル) → 8px
999px(バッジ、タブ、ナビ、進捗)             → 角丸なし(印・下線・細い線に置き換え)
```

影(13種類 → 1種類)

```
モーダル、お知らせ                         → 0 8px 24px rgba(31,30,27,0.18)
ヘッダー、ボタン、カード、要約、タブ、ナビ → なし(罫線で区切る)
入力欄のフォーカスの影                     → 2pxの輪郭線
```

