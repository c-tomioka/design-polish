## after.html と diagnosis.md

before.html を書いたエージェントとは別のサブエージェントに、次の依頼文をそのまま渡して生成させた。サブエージェントはこの会話の経緯を知らず、スキルの文面だけを頼りに作業している。**出力は手で整えず、そのまま置いている。**

```
次のスキルを読み、その手順に従って作業してください。

- スキル本文: (リポジトリ)/skills/design-polish/SKILL.md
- 本文が参照している references/ と assets/ は、本文が読むように指示している場合に読んでください
- Skill ツールは使わず、上のファイルを直接読んでください。このスキル以外のデザイン指針や、リポジトリ内の他の見本(docs/ 配下の他のフォルダ)は見ないでください

依頼: 「この画面のデザインを良くしてください。任せます。」
対象: (リポジトリ)/docs/examples/dashboard/before.html

出力:
1. 修正後の画面を、同じフォルダに after.html として保存する(before.html は変更しない。CSSとスクリプトをインラインにした1ファイル。外部の読み込みは禁止)
2. スキルの「診断の出力形式」に沿った診断と方向性、および手順8の報告を、同じフォルダに diagnosis.md として保存する

ユーザーは不在です。確認は取らずに最後まで進めてください。前後比較ページは別に用意するので作らなくて構いません。

最後に、次の2点を報告してください。
- 行った検証(コントラスト比は計算した値を書く)
- SKILL.md の文面だけでは判断に迷った箇所、足りなかった箇所、うまく従えなかった箇所(なければ「なし」)
```

依頼文中の「(リポジトリ)」は、実際には作業環境の絶対パス。
